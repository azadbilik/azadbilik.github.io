# Şəki

[azadbilik.org/gezinti/seki](https://azadbilik.org/gezinti/seki/): 29 places in Yuxarı Baş and the bazaar quarters, and three walks.

Build with `node gezinti/scripts/build.mjs seki`; how the data is made is in [../README.md](../README.md).

- **Şəkixanovların evi:** placed at the OSM point west of the palace. Wikidata puts it inside the fortress beside the palace, but the articles say it stands "a few blocks away", west of the palace.
- **Xan məscidi (Q5364087):** its Wikidata label is «Cümə məscidi», so the name is set by hand.
- **Xan qəbiristanlığı:** shares that mosque's point in Wikidata, so it is set about 15 m south of it. Its exact position is not known.
- **Left out:** Şəki Sənətkarlar Evi, which has no article.
- **Abdulxalıq hamamı:** off the walks, because it is 600 m north of the others.
- **Not here:** the Albanian church in Kiş, 5 km away. It is for a later walk.
